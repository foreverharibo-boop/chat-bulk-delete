# 채팅방 일괄 삭제 v3.0.0

실리태번 채팅 기록에서 여러 방을 선택해 삭제하고, 내용이 같은 채팅을 확인하는 간단한 확장입니다.

## 설치 / 업데이트

확장 설치 주소: https://github.com/foreverharibo-boop/chat-bulk-delete

기존 사용자는 확장 관리에서 업데이트한 뒤 새로고침합니다. 별도 서버 플러그인은 필요하지 않습니다.
수동 설치 파일: `manifest.json`, `index.js`, `batch.js`, `chat-data.js`, `duplicates.js`, `style.css`.

## 사용 방법

1. 실리태번의 채팅 기록 창을 엽니다.
2. **선택**을 누르고 지울 방을 체크합니다. **현재 목록 전체 선택**과 **선택 해제**도 사용할 수 있습니다.
3. **삭제 (선택 개수)**를 누릅니다.
4. 확인창에서 방 이름·개수를 확인하고 **영구 삭제**를 누릅니다. 취소하면 삭제하지 않습니다.

삭제는 휴지통을 거치지 않는 영구 삭제입니다. 이 확장으로 되돌릴 수 없습니다. 기존 채팅 기록의 삭제 아이콘에도 같은 확인창을 적용합니다.
현재 캐릭터/그룹에서 선택한 방만 삭제합니다. 현재 열린 방은 저장 상태를 확인해 마지막에 삭제하며, 답변 생성 중이거나 대상이 바뀌면 작업을 중단합니다. 다른 그룹이 함께 사용하는 파일은 삭제하지 않습니다.
실패한 방은 남기고 처리 결과를 표시합니다. 작업 중 표시되는 **중단**은 진행 중인 서버 요청 이후의 처리를 멈춥니다.
실리태번 기본 이름 검색은 그대로 사용합니다. 검색이나 목록이 바뀌면 선택을 해제합니다.

## 중복 확인

**중복 확인**을 누르면 현재 캐릭터/그룹의 저장된 전체 채팅을 읽고, 같은 내용끼리 같은 색상과 **같은 내용 1 · 3개** 같은 번호·개수를 표시합니다. 중복 표시가 있는 방도 삭제할 대상은 직접 선택합니다. 자동 선택·자동 삭제는 하지 않습니다.

- 대화 전체의 메시지 순서, 발화자, 선택된 원문, 사용자/시스템 구분(숨김 상태), 첨부 정보를 비교합니다. 공백과 줄바꿈도 비교합니다.
- 방 이름·설정, 시각, 토큰 수, 번역문, 선택하지 않은 스와이프, 확장 부가 정보는 비교에서 제외합니다. 같은 내용으로 표시돼도 이 정보들은 다를 수 있습니다.
- 같은 그리팅만 있는 방도 비교할 수 있습니다. 분기 이후 내용이 다르면 같은 묶음으로 표시하지 않습니다.
- 지문이 일치해도 전체 내용을 다시 비교합니다. 읽기 실패나 검사 중 변경된 방은 제외하며, 중단 시 불완전한 결과를 표시하지 않습니다.
- 검사는 읽기 전용이며 원문을 저장하거나 삭제하지 않습니다. 현재 열린 대화가 저장된 파일과 다르면 그 방은 제외합니다.
- 메시지 수정·스와이프·이름 변경·삭제·채팅 전환 시 표시를 해제합니다. 다른 기기의 변경은 즉시 감지하지 못하므로 필요하면 다시 검사합니다.

## v3.0.0 변경

남긴 기능: 선택·전체 선택/해제, 삭제 확인·일괄 삭제, 중복 확인·표시, 작업 중 진행 상황·중단.

휴지통·복원, 채팅 잠금, ZIP 백업, 추가 정렬·필터를 제거했습니다. 기존 잠금은 더 이상 삭제를 막지 않습니다.
예전에 서버 `user/files/`에 저장한 `cbd-v2-state.json`과 `cbd-v2-trash-*.json`은 삭제하거나 변경하지 않습니다. 새 버전에는 이 보관본을 여는 화면이 없습니다. 기존 휴지통에서 복원할 것이 있다면 업데이트 전에 v2.2.1에서 복원해 주세요. 이미 업데이트했다면 v2.2.1 소스로 되돌려 기존 보관본에 접근할 수 있습니다.

## 검증

```sh
node --test tests/batch.test.mjs tests/integration.test.cjs tests/delete-scope.test.cjs tests/checkbox.test.cjs tests/safety-regressions.test.cjs tests/duplicates.test.mjs
```

모의 채팅 데이터로 캐릭터/그룹별 선택 범위, 확인 취소, 현재 대화 변경·생성 중 중단, 중복 검사, 기존 보관 데이터 보존을 검증합니다. 실제 사용자 채팅을 삭제하는 검사는 하지 않습니다.
