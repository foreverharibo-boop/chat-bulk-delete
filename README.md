# 채팅방 일괄 삭제 v1.0.1

실리태번의 채팅 기록 창에서 여러 채팅방을 선택해 한 번에 삭제하는 확장입니다.
기존 채팅 기록 화면에 작은 선택 도구만 추가하며 실리태번 테마색을 사용합니다.

## 설치

실리태번의 **확장 → 확장 설치**에서 아래 주소를 붙여 넣습니다.

```text
https://github.com/foreverharibo-boop/chat-bulk-delete
```

설치 후 화면을 새로고침합니다. 새 버전이 있으면 실리태번 확장 화면에서 업데이트할 수 있습니다.

### ZIP으로 수동 설치

1. ZIP을 압축 해제합니다.
2. `chat-bulk-delete` 폴더를 실리태번의 `data/default-user/extensions/` 안에 넣습니다.
   다중 계정을 쓰는 경우 `default-user` 대신 실제 계정 폴더를 사용합니다.
   구버전에서 이 경로를 사용하지 않는 경우 `public/scripts/extensions/third-party/` 안에 넣습니다.
3. 실리태번 화면을 새로고침합니다.

폴더 안에 `manifest.json`, `index.js`, `batch.js`, `style.css`가 바로 있어야 합니다.
이 ZIP은 확장 설치창의 Git 주소 입력칸에 넣는 파일이 아닙니다.

## 사용

1. 캐릭터 또는 그룹의 **채팅 기록** 창을 엽니다.
2. **여러 개 선택**을 누르고 체크박스 또는 채팅 카드를 눌러 선택합니다.
3. **현재 목록 전체 선택**은 지금 검색 결과에 표시된 방을 모두 선택합니다.
   검색어를 바꾸더라도 이전에 선택한 방은 유지됩니다. 선택 삭제의 숫자는 전체 선택 개수입니다.
4. **선택 삭제**를 누르고 삭제할 이름과 개수를 확인한 뒤 삭제를 확정합니다.

- 현재 열린 방은 마지막에 삭제합니다. 삭제 후 남은 채팅방을 열고, 모두 삭제했다면 새 채팅을 엽니다.
- 답변 생성 중에는 삭제를 시작할 수 없습니다.
- 삭제 중에는 화면 조작을 잠시 막습니다. **중단**을 누르면 현재 서버 요청이 끝난 뒤 다음 삭제부터 멈춥니다.
- 삭제에 실패한 방은 선택을 유지하고 결과를 표시합니다. 서버 요청을 자동 재시도하지 않습니다.
- 삭제 후 실리태번 기본 기능으로 목록을 새로 불러옵니다. 검색어는 초기화됩니다.
- 선택 취소 또는 채팅 기록 창을 닫으면 선택 상태가 초기화됩니다.
- 채팅 파일만 삭제합니다. 캐릭터, 프리셋, 로어북은 삭제하지 않습니다.
- 실행 취소/백업 기능은 제공하지 않습니다. 실리태번 자체 백업이 있는지는 이 확장이 보장하지 않습니다.
- API 키나 서버 플러그인 없이 실리태번 자체 채팅 API를 사용합니다.

## v1.0.1 변경 사항

- 체크박스를 눌렀을 때 체크 표시가 되돌아가는 문제를 수정했습니다.
- 체크박스 테두리와 체크 표시는 실리태번 테마 글자색을, 배경은 테마 배경색을 따릅니다.
- 선택 삭제 대상과 삭제 방식은 그대로 유지됩니다.

## 확인 범위

실리태번 공식 소스의 채팅 기록 DOM과 삭제 API를 확인하고,
모의 서버를 이용해 삭제 순서, 실패 처리, 현재 방 전환, 그룹 목록 저장을 테스트했습니다.
브라우저 실행 파일을 받지 못해 모바일/PC의 실제 화면 동작은 확인하지 못했습니다.
실제 사용자 서버와 저장된 대화를 대상으로 삭제 테스트는 하지 않았습니다.
