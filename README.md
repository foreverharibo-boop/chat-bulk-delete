# 채팅방 일괄 관리 v2.1.3

실리태번 채팅 기록 창에 휴지통·복원, 잠금, 채팅별 ZIP 백업, 정렬·필터를 추가합니다.
모바일 화면에 맞춰 도구가 줄바꿈되며 실리태번 테마색을 사용합니다.

## 설치 / 업데이트

**확장 → 확장 설치**에서 다음 주소를 입력합니다.

```text
https://github.com/foreverharibo-boop/chat-bulk-delete
```

이미 설치했다면 확장 관리 화면에서 업데이트한 뒤 새로고침합니다. 버전은 **2.1.3**입니다.
수동 설치 시 `manifest.json`, `index.js`, `batch.js`, `vault.js`, `zip.js`, `view.js`, `duplicates.js`, `style.css`를 같은 확장 폴더에 둡니다.

### v2.1.3 수정

- 같은 그리팅/대화가 토큰 수, 스와이프 기록, 확장 부가 정보 차이 때문에 중복에서 빠지던 비교 기준을 수정했습니다.
- 전체 대화의 선택된 원문·순서·발화자·숨김 상태·첨부 정보를 비교합니다. 번역과 선택하지 않은 스와이프, 방 설정은 다를 수 있습니다.

### v2.1.2 수정

- 정렬과 필터를 모바일에서도 같은 줄에 나란히 표시하도록 두 열로 고정했습니다.

### v2.1.1 수정

- 휴지통·잠금 데이터를 읽을 때 발생하던 `Failed to execute 'fetch' on 'Window': Illegal invocation` 오류를 수정했습니다. 브라우저의 `fetch` 호출 대상을 유지하도록 변경했습니다.
- 브라우저와 같이 호출 대상을 검사하는 모의 `fetch`로 목록 읽기, 잠금, 보관본 검증, 복원 과정을 재검증했습니다.

## 휴지통과 복원

1. 채팅 기록에서 **선택**을 누르고 원하는 방을 선택합니다.
2. **휴지통으로**를 누르고 확인창의 이름과 개수를 확인합니다. 잠긴 방은 제외됩니다.
3. 서버에 보관본을 저장하고 다시 읽어 내용이 일치하는지 확인한 후에만 원본 삭제를 요청합니다.
4. **휴지통 / 복원**에서 현재 캐릭터 또는 그룹의 보관 내역을 볼 수 있습니다.
5. **복원**을 누르면 원래 캐릭터/그룹에 `원래 이름 - 복원 고유번호`라는 새 이름으로 저장합니다. 복원 후 기존 연필 버튼으로 이름을 바꿀 수 있습니다.

- 기존 이름의 채팅을 덮어쓰지 않습니다. 복원 내용도 보관본과 비교합니다.
- 보관본은 복원 후에도 남습니다. 자동 비우기·영구 삭제 기능은 제공하지 않습니다.
- 삭제 요청이나 상태 기록이 중간에 끊기면 **보관됨 · 원본 삭제 여부 확인 필요**로 남을 수 있습니다. 원본이 있는지 확인하고 필요한 경우 복원하세요.
- 원래 캐릭터/그룹이 없거나 JSONL 형식에 문제가 있어 자동 복원이 안 되면 **JSONL 받기**로 원본 내용을 내려받을 수 있습니다.
- 채팅 기록의 기본 삭제 아이콘도 이 확장의 휴지통 절차로 연결합니다.
- **중단**은 이미 서버에 보낸 삭제 요청을 취소하지 못합니다. 보관 단계에서는 원본 삭제 전에 멈추고, 삭제 요청이 진행 중이면 다음 방부터 멈춥니다.
- v1.x에서 이미 삭제한 파일은 이 휴지통에 소급해서 나타나지 않습니다.

## 채팅 잠금

- 각 방 오른쪽 세로 중앙의 자물쇠 버튼으로 잠금/해제를 설정합니다.
- **현재 목록 전체 선택**은 화면에 보이는 잠기지 않은 방만 선택합니다.
- 잠긴 방을 직접 선택하면 ZIP 백업은 할 수 있지만 휴지통 이동에서는 제외됩니다.
- 기본 채팅 이름 변경 이벤트에 연결해 잠금을 새 이름으로 옮깁니다.
- 같은 이름이라도 캐릭터/그룹이 다르면 잠금이 별도로 적용됩니다.
- 잠금은 이 확장의 일괄 삭제와 채팅 기록의 삭제 버튼을 보호합니다. 다른 확장·슬래시 명령·서버 직접 삭제까지 차단하는 서버 권한 기능은 아닙니다.

## 선택한 방을 각각 ZIP 백업

방을 선택하고 **선택 ZIP 백업**을 누르면 ZIP 하나 안에 **방마다 별도의 `.jsonl` 파일**이 들어갑니다.

- 채팅 이름을 파일명으로 사용합니다. 이름 충돌·금지문자는 안전하게 처리해 덮어쓰지 않습니다.
- 한글·이모지와 대화의 메타데이터/스와이프 등을 포함한 원본 JSONL을 보존합니다.
- 다운로드 중 일부 방을 읽지 못하면 불완전한 ZIP을 성공으로 내보내지 않습니다. 방을 다시 선택해 재시도하세요.
- ZIP은 호환성을 위해 무압축 ZIP 형식으로 묶습니다. 파일 크기를 줄이는 압축은 하지 않습니다.
- 캐릭터 카드, 이미지·첨부파일의 실물, 프리셋은 포함하지 않습니다. 채팅에 기록된 첨부 경로는 그대로 남습니다.
- 브라우저 메모리를 사용하므로 큰 채팅이 많으면 나눠서 백업하세요. 실제 다운로드 완료 여부는 브라우저 다운로드 목록에서 확인합니다.

## 정렬 / 필터

- 정렬: 최신순, 오래된순, 오름차순(이름), 내림차순(이름), 용량 큰순, 메시지 많은순.
- 이름순은 변경된 실제 채팅방 이름을 사용하며 `방 2`가 `방 10`보다 앞에 옵니다.
- 필터: 전체 / 잠긴 방 / 안 잠긴 방 / 같은 내용만. 정렬과 함께 적용할 수 있습니다.
- 별도 이름 검색칸을 없애고 상단 실리태번 기본 검색칸을 사용합니다.
- 검색·정렬·필터 또는 목록을 바꾸면 선택을 해제합니다. 숨겨진 선택을 유지하지 않습니다.

## 내용이 같은 채팅 표시

**중복 확인**을 누르면 현재 캐릭터/그룹의 저장된 전체 채팅 기록을 차례로 읽습니다.
내용이 같은 방끼리 같은 색상과 **같은 내용 1 · 3개** 같은 번호/개수 표시가 붙습니다.
검사 후 필터의 **같은 내용만**을 선택하면 표시된 방만 볼 수 있습니다.

- 메시지 개수·순서·발화자·선택된 스와이프의 원문(`mes`)·사용자/시스템 구분(숨김 상태)·첨부 정보를 비교합니다. 숨긴 메시지도 포함하며 공백과 줄바꿈을 그대로 비교합니다.
- 채팅 이름, 방 설정/분기 정보, 시각, 토큰 수, 생성 정보, 확장 부가 정보는 제외합니다. 선택하지 않은 스와이프와 번역문도 비교하지 않습니다.
- 같은 그리팅만 있는 방은 위 비교 항목이 같으면 같은 묶음으로 표시합니다. 앞부분만 같고 분기 이후 내용이 달라진 방은 제외합니다. 목록의 짧은 미리보기만 비교하지 않습니다.
- 지문으로 후보를 찾은 뒤 전체 비교 내용을 다시 대조합니다. 지문만 같다는 이유로 동일 판정하지 않습니다.
- 검사 과정은 읽기 전용입니다. 채팅 저장·삭제·이동·자동 선택은 하지 않습니다. 현재 열린 방의 저장 상태가 화면과 다르면 해당 방은 검사에서 제외합니다.
- 중단하면 일부 결과를 완성된 결과처럼 표시하지 않습니다. 읽기 실패한 파일도 동일 판정에서 제외합니다.
- 대화 수정·스와이프·이름 변경·삭제·채팅 전환이 감지되면 표시를 해제합니다. 다른 기기에서의 변경은 즉시 감지하지 못하므로 정리 전 다시 검사하세요.
- 많은 대화를 읽으면 시간이 걸립니다. 서버에 요청을 한꺼번에 보내지 않고 순차 처리하며, 검사 결과/대화 원문을 별도로 저장하지 않습니다.
- 이 표시는 원문 대화 비교 결과이며 파일 전체가 같다는 뜻은 아닙니다. 방 설정·번역·선택하지 않은 스와이프는 다를 수 있으므로 보관할 내용을 확인하고 삭제할 방은 직접 선택하세요.

## 보관 위치와 제한

휴지통 보관본과 잠금 목록은 현재 실리태번 사용자 계정의 서버 `files/` 폴더에 저장합니다.
`cbd-v2-state.json`이 목록이고 `cbd-v2-trash-고유번호.json`이 원문과 원래 대상을 담은 개별 보관본입니다.
외부 서비스로 대화를 전송하지 않으며 별도 서버 플러그인은 필요하지 않습니다.

휴지통은 같은 서버에 있으므로 서버 전체 유실에 대비하는 독립 백업은 아닙니다. 중요한 대화는 ZIP도 다른 곳에 보관하세요.
파일 API에는 여러 기기의 동시 쓰기를 원자적으로 잠그는 기능이 없으므로 휴지통·잠금 작업은 한 기기/탭에서 진행하세요.
다른 기기나 확장이 동시에 채팅 파일을 수정하는 경우까지 완전히 통제하지 못합니다.
서버의 파일 업로드/읽기 API를 사용할 수 없으면 휴지통 이동은 중단합니다.

## 검증

공식 실리태번 API 소스를 확인하고 모의 서버에서 다음을 검사했습니다.

- 32가지 선택 조합과 다른 캐릭터의 동명 파일 보존.
- 보관 업로드·목록 기록·재읽기 실패 시 삭제 요청 차단.
- 보관 중 원본 변경·대상 변경, 잠긴 방, 공유 그룹 파일 삭제 차단.
- 새 이름 복원, 대화 내용 일치, 그룹 정보 보존, 보관본 유지.
- 잠금 저장·이름 변경, 정렬·필터, 숨은 선택 초기화.
- Python `zipfile`로 개별 UTF-8 JSONL 파일 내용과 ZIP CRC 검증.
- 같은 그리팅의 부가 정보 차이/전체 대화·분기·첨부 차이/지문 충돌/검사 중단 검증, 중복 검사에 저장·삭제 요청이 없는지 확인.

```sh
node --test tests/batch.test.mjs tests/integration.test.cjs tests/delete-scope.test.cjs tests/checkbox.test.cjs tests/safety-regressions.test.cjs tests/features.test.mjs tests/duplicates.test.mjs
```

테스트에는 Node.js와 Python이 필요합니다. 실제 사용자 서버의 대화를 삭제하는 테스트는 하지 않았습니다.
브라우저 실행 환경을 확보하지 못해 실제 모바일/PC 화면의 시각적 동작은 검증하지 못했습니다.
